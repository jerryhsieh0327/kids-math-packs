# kids-math-packs
Daily Apple-Pencil math quizzes (iPad Safari) at https://jerryhsieh0327.github.io/kids-math-packs/

## Layout
- `assets/quiz.js`, `assets/quiz.css` – shared kid-page template (canvas, Undo/Clear, Done → PNG overlay, Share/Download/Copy report).
- `YYYY-MM-DD/quiz.json` – source of truth (English questions, answers, steps, mistakes).
- `YYYY-MM-DD/index.html` (kid, no answers) and `parent.html` are GENERATED by `build.py`.

## New date
1. `mkdir 2026-10-26 && cp 2026-10-25/quiz.json 2026-10-26/` and edit (date, label "", topic, 5 questions + 1 `"challenge": true`). Verify answers.
2. `./build.sh` (runs build.py + node --check).
3. Publish via Composio GitHub (account jerryhsieh0327): `GITHUB_COMMIT_MULTIPLE_FILES` owner=jerryhsieh0327 repo=kids-math-packs branch=main, upserts = `index.html`, `DATE/quiz.json`, `DATE/index.html`, `DATE/parent.html` (content `$file:/workspace/kids-math-packs/<path>`). Also upsert `assets/*` if changed (bump `?v=` in build.py).
4. Open https://jerryhsieh0327.github.io/kids-math-packs/DATE/ and wait until it loads (HTTP 200, about 1 minute after the commit).
